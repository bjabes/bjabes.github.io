How This Translation Was Made

Behind the scenes

This translation was created as a personal project to make an important piece of gaming history accessible to English readers. Gunpei Yokoi Game Museum has never been officially translated into English, despite being one of the most insightful primary sources on Nintendo's creative philosophy. This project set out to change that, using a multi-stage AI-assisted pipeline designed to produce a translation that reads like natural English while staying faithful to the original Japanese.

The Pipeline

The translation was not a single pass. It was built through four distinct stages, each addressing a different dimension of quality. The idea was to treat AI not as a replacement for editorial judgment, but as a tireless first-draft engine that could be iteratively refined.

Stage 1: Vision-Based Draft Translation

The original Chikuma Bunko paperback was scanned as a PDF. Rather than relying on OCR to extract text (which struggles with Japanese vertical typesetting), each page image was sent directly to Claude's vision API (claude-sonnet-4-6). The model read the Japanese text from the page image and produced an English translation in a single pass.

To maintain narrative flow across page breaks, each page was translated with the previous page's translation included as context. This prevented the model from losing track of mid-sentence breaks, ongoing dialogue, or thematic threads. The entire book (231 content pages) was processed this way, with each page's translation cached as a JSON file for reproducibility.

The system was designed to handle edge cases automatically: if a page produced a suspiciously short response (suggesting the model couldn't read the image), it retried at a higher DPI. Rate limits and API errors triggered exponential backoff with automatic retries.

Stage 2: Expert Revision Pass

The initial Sonnet drafts were competent but sometimes literal. A second pass sent every page to Claude Opus (claude-opus-4-6) — a more capable and expensive model — with three inputs: the original page image, the extracted Japanese text from the PDF, and the existing English draft. The revision prompt instructed the model to act as an expert Japanese-to-English literary translator, aggressively correcting mistranslations, omissions, awkward phrasing, and OCR artifacts while preserving the page's structure and information.

This stage was the most expensive part of the pipeline, but it made the biggest difference in quality. Where Sonnet might produce a correct but stiff translation, Opus would reshape sentences into prose that felt written, not translated.

Stage 3: English Editorial Review

The third stage was a pure English-language editorial pass. A separate AI reviewer read each chapter as assembled continuous prose — without access to the Japanese source — and flagged issues a native English reader would notice: translation-ese, repetitive word choices, inconsistent terminology, unclear antecedents, and tonal shifts.

The reviewer produced structured find-and-replace edits with categories (phrasing, word-choice, consistency, clarity, flow, tone) and explanations. These edits were validated programmatically to ensure every "find" string actually appeared in the text, with fuzzy matching to recover near-misses caused by whitespace or quote normalization differences.

Stage 4: Glossary Standardization

A canonical glossary was built to enforce consistency across the entire book. Key decisions included always using English name order (Gunpei Yokoi, not Yokoi Gunpei), standardizing Yokoi's famous philosophy as "Lateral Thinking with Seasoned Technology" (not "Withered Technology," a common mistranslation), and maintaining consistent terms like "Idea Toys" and "Light Gun" throughout. The glossary was applied as automated regex replacements across all pages, catching any variants the editorial pass missed.

Quality Note

This is an AI-assisted translation, not a professional human translation. The multi-stage pipeline produces remarkably natural English, but there may be errors — especially with idiomatic expressions, wordplay, or cultural references that require deep contextual knowledge. The interview sections, where Yokoi speaks in his own voice, were particularly challenging: the goal was to preserve his conversational, sometimes meandering style without making him sound stilted or overly polished.

If you spot an error, contributions and corrections are welcome.

The Tools

The entire pipeline is built in Python. PyMuPDF handles PDF page extraction and image rendering. The Anthropic API powers every translation and review stage. A custom static site generator produces this reading experience, complete with page-image thumbnails in the margins, a lightbox viewer, and chapter navigation. The total API cost for translating and refining the entire book was approximately $10.89.
